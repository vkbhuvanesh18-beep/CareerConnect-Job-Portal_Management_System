01. Context

Introduction and industry background

Recruitment portals connect job seekers with employers, but high volumes of generic listings make relevant opportunities difficult to find.

Recruiters also need a quick way to compare applicants against job requirements without manually reviewing every profile.

CareerConnect focuses on structured profile data, job requirements, transparent matching, and application tracking.

02. Define

Problem statement and real-world inefficiencies

Generic listings

Job seekers spend time opening irrelevant or outdated posts.

Manual screening

Recruiters compare skills and experience by hand for each candidate.

Unclear progress

Candidates need a clear view of application stages and interview updates.

04. Solution

Proposed centralized three-tier solution

Presentation layerThymeleaf, HTML5, CSS Grid/Flexbox, Fetch API
Application layerSpring Boot MVC, Security, matching, notifications
Persistence layerJPA repositories, H2 local database, MySQL profile

One portal connects candidate activity, recruiter actions, and persistent data.

05. Objectives

Project objectives

Relevant applications

Collect verified skill tags, education, experience years, and portfolio information.

Explainable matching

Calculate a 0 to 100 compatibility score from required skills and experience.

Recruiter workflow

Post jobs, filter candidates by score, update stages, and schedule interviews.

Candidate updates

Create in-portal notifications when an application stage changes.

06. Implemented features

Key functional features

  • Registration and login with BCrypt password hashing
  • Job seeker profile with skill tags, qualification, experience, and portfolio URL
  • Job posting with required skills and minimum experience
  • Compatibility score using 80% skills and 20% experience
  • Application stages: Applied, Shortlisted, Interview, Offered, Rejected
  • Admin score filter, interview scheduling, and in-portal notifications
